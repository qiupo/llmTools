# llmTools v0.5.0

`v0.5.0` focuses on local speech generation, streaming speech recognition, richer translation output, and a dedicated OCR pipeline that keeps recognition and text processing under explicit model control.

## 功能与修复

- 本地 VoxCPM2 文案转语音：支持 bf16/4bit 模型、Quick Action 直接生成、音色与语气选择、试听/播放，以及 WAV/M4A 导出。
- 多角色 TTS 工作台：按确定性原文单元分析角色，支持审阅、断点续生成、项目保存、音色管理和 SRT 导出；TTS runtime 与 ASR/会议管线保持隔离。
- 翻译详解：可使用独立质量模型生成主译文、候选译法、重点词汇、发音、用法和例句；可选字段格式异常时仍保留合法主译文。
- Nemotron 流式 ASR：新增 FluidAudio/Nemotron 实时识别路径、基准工具和模型注册工具，并保留既有本地 ASR 路由。
- GLM-OCR 专用链路：专用视觉模型负责文字识别，结构化、解释和 OCR 后翻译可选择独立文字模型；历史与状态栏展示完整模型链。
- OCR 可靠性：长篇结构化结果不再经过可能截断的短输出后处理；未配置文字模型时仍可直接使用 GLM-OCR 的结构化结果，解释/翻译会给出明确配置错误。
- 本地思考模式兜底：首轮达到 token 上限时，即使已生成少量正文也会关闭思考并完整重试，避免把截断翻译、JSON 或角色分析保存为成功结果。
- Quick Action 状态：文本、图片、媒体和语音标签分别保存结果及真实模型名，切换标签后状态栏不再显示另一任务的模型。
- 运行时与检查：补充 OCR 双阶段、偏好迁移、长文档 fallback、思考截断、Quick Action 状态和真实模型 smoke 覆盖。

## 使用方法

1. 从本 Release 下载 `llmTools-v0.5.0-macos-arm64.zip`，解压后把 `llmTools.app` 移到 `/Applications` 或其他可信目录。
2. 首次启动时按需授予 Accessibility、麦克风和屏幕录制权限。该构建使用 ad-hoc 签名且未 notarize，必要时从 Finder 的“打开”或“系统设置 -> 隐私与安全性”允许启动。
3. 文案转语音使用“状态栏菜单 -> 文案转语音”，按“检查/修复”安装独立 VoxCPM2 runtime，并在音色管理中准备音色后生成。
4. 图片识别使用“设置 -> OCR”选择视觉识别模型；使用 GLM-OCR 时，可另选“后处理模型”，留空则跟随 Text 默认模型。
5. 结构化 OCR 在短文档上可由文字模型整理 Markdown；长文档直接保留专用 OCR 的结构结果，避免二次生成截断。
6. 网页翻译扩展仍为开发通道；升级后请在 `chrome://extensions` 或 `edge://extensions` 重新加载本 Release 附带的 unpacked extension。

## 说明

- TTS、ASR、说话人处理和会议纪要保持 local-only，不会回退到远程 Provider。
- VoxCPM2 模型权重不打入 app；安装脚本复用本机已有模型，只有显式允许时才下载资源。
- Provider API key 继续保存在本地 `model-registry.json`，不接入 macOS Keychain。
- Chromium 扩展仍为手动加载的开发版本，不是 Chrome Web Store 分发版本。
- macOS app 使用 ad-hoc 签名且未 notarize。
